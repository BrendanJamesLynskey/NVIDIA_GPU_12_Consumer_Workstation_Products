# GeForce, RTX Pro, Tesla & A/H/L/B — Decoding NVIDIA's Product Lineup

A field guide to every NVIDIA product family — consumer GeForce, workstation RTX Pro (the line formerly known as Quadro), datacenter A/H/L/B (formerly Tesla), Jetson edge AI, and the China-export A800/H800/H20 variants. Covers EULA boundaries, driver branches, the "same die different card" phenomenon, and how to pick the right SKU for each role. Includes an interactive card-to-use-case mapper.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_12_Consumer_Workstation_Products/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
